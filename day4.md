  * Java
  * Data Structures & Algorithms (DSA)
  * Git & GitHub
  * Portfolio Website Development

* Included learning milestones, project ideas, growth strategies, and long-term career objectives.

What I Learned:

1. Importance of Having a Roadmap

I learned that having a clear roadmap helps avoid random learning and keeps me focused on skills that directly contribute to my career goals.

2. Skill Gap Analysis

I understood that while I have a strong foundation in Java, DSA, and Git/GitHub, I need to improve in:

* Python
* Machine Learning
* Deep Learning
* Generative AI
* LangChain & RAG
* Cloud Deployment
* MLOps

3. Project-Based Learning Matters

I learned that building real-world projects is more valuable than only watching tutorials. Projects help demonstrate practical skills and strengthen my portfolio.

4. Consistency Beats Motivation

Success in AI is not about learning everything quickly. Consistent daily learning and project building create long-term growth.

5. Building in Public

Sharing projects, learnings, and progress on GitHub and LinkedIn helps build credibility, improve networking opportunities, and attract recruiters.

6. AI Career Growth Requires Multiple Skills

To become an AI Engineer, I need a combination of:

* Programming Skills
* Mathematics & Statistics
* Machine Learning
* Deep Learning
* Generative AI
* Deployment & Cloud Technologies
* Communication & Problem Solving
