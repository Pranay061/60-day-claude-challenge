Day 3 – Role-Based Prompting 

1.What I Did:

Today, I explored Role-Based Prompting, a prompt engineering technique where a specific role is assigned to Claude AI before asking a question.

I designed an infographic explaining:

* What Role-Based Prompting is
* Why it is useful
* Where it can be applied
* How to use it effectively
* The difference between prompts with and without assigned roles
* How different professional roles provide unique perspectives on the same problem

2.What I Learned:

1. Role-Based Prompting Improves AI Responses

By assigning a role such as:

* Developer
* Data Analyst
* UX Designer
* Marketing Expert
* Product Manager
* AI Researcher

AI generates more focused, relevant, and expert-level responses.

2. Context Matters

A generic prompt often produces broad answers, while role-based prompts provide:

* Better context
* Greater accuracy
* Actionable recommendations
* Domain-specific insights

3. Same Question, Different Perspectives

The same question can receive completely different answers depending on the assigned role.

Example:
Question: How can I improve engagement in my learning app?

* Developer → Focuses on features and performance
* Data Analyst → Focuses on user behavior and metrics
* UX Designer → Focuses on user experience
* Marketing Expert → Focuses on campaigns and retention
* Product Manager → Focuses on strategy and prioritization
* AI Researcher → Focuses on personalization and AI features

4. Elements of an Effective Role-Based Prompt

A strong prompt should include:

* Clear role
* Specific goal
* Context
* Constraints
* Desired output format
* Audience information
